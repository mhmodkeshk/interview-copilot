# Interview Copilot — محمود كشك

تطبيق صفحة واحدة (HTML) لتحضير إنترفيوهات الشركات الألمانية.
يفتح على الموبايل واللابتوب، ويشتغل أوفلاين، وتقدر تضيف/تعدّل/تحذف بنفسك.

## الشكل
- **شمال الشاشة:** مربعات صغيرة، كل مربع فيه السؤال **بالألماني** وتحته العربي.
- **يمين الشاشة:** الإجابة داخل برواز، بخط كبير، فيها مشغّل الصوت.

## إزاي تفتحه
- **لابتوب:** دبل كليك على `index.html` (Chrome / Edge).
- **موبايل (نفس الشبكة):**
  ```
  python -m http.server 8080
  ```
  وافتح من الموبايل: `http://IP-اللابتوب:8080`
- **موبايل أوفلاين:** انقل الفولدر كله (مش `index.html` لوحده، عشان ملف الصوت يشتغل).

## المميزات
- بحث فوري عربي/ألماني (كل الأسئلة في قايمة واحدة — بدون فلترة تصنيفات).
- تبويبان لكل سؤال: **الإجابة** / **المعنى بالعربي**.
- 🔎 تصغير/تكبير نص الإجابة **بصوبعين (pinch)** جوه البرواز، أو بزراير `A−` / `A+`،
  وزر **⤢** بيظبط الحجم تلقائيًا لأكبر قدر يبان من الإجابة في الشاشة.
- 🔊 صوت لكل سؤال: ترفع MP3/M4A/WAV، بيتحفظ جوه التطبيق ويشتغل أوفلاين.
- ✏️ تعديل أي سؤال/إجابة + إضافة سؤال جديد + ترتيب + حذف.
- ★ تثبيت الأسئلة المهمة.
- 🆘 جمل الإنقاذ (الشبكة ضعيفة، أعِد السؤال، لحظة أفكر…).
- وضع **تدريب** يخفي الإجابة لحد ما تدوس "اكشف".
- 💾 نسخة احتياطية / ⇪ استيراد (اختياري مع الصوت).
- كيبورد: `/` بحث · `Esc` رجوع · `↑ ↓` تنقل بين الأسئلة.

## ملاحظات
- البيانات محفوظة **داخل المتصفح** — الموبايل واللابتوب كل واحد ليه نسخة، انقل بينهم بالنسخة الاحتياطية.
- الصوت المرفوع بيتحفظ في IndexedDB (أو localStorage لو غير متاح).
- صوت الإجابة التجريبي المرتبط بالسؤال الأول في ملف `demo-vorstellung.mp3`
  (نسخة MP3 من التسجيل الأصلي `WhatsApp Audio 2026-10-23 at 11.31.53 PM.mpeg`).
